(VR≈1.00 all 12)**; 5M aggregate VR<1 is **microstructure (bid-ask bounce in AVAX/TON) that vanishes
at 1H**; post-breakout revert≈continue (~36% each). VR(q)=Var(q-bar ret)/(q·Var(1-bar ret)): <1 mean-revert, ≈1 random walk, >1 trend.

### 3c. FADE strategy definition — `crt_engine.py:423` `detect_h4_crt(...)` (FADE_CRT_DIAGNOSIS.md)
The production fade = **H4 Candle Range Theory, sweep→reverse (mean-reversion)**. "Per the Wyckoff/
flexible school — the sweep candle's BODY close position is NOT decisive; what confirms the setup is
the subsequent control change, detected via 5M MSS within `H4_CRT_MSS_HORIZON` bars after C2's close."
Same C1-range `consumed` one-shot semantics as the breakout engine. Runs live as `crypto_alert.py`
(PID 512666). **Note (overlap):** MEAN_REVERSION_EXPLORATION concludes a generic MR strategy would
**duplicate the fade**, not be new — and since no broad MR property exists at 1H, the fade's edge (if
any) is setup-specific, not a general token property.

## 4. CONVENTIONS

- **Libraries (data + stats):** **pure-python / custom — NO pandas, polars, statsmodels, or numpy**
  in the breakout/analysis path. Uses `json, bisect, math, statistics, os, sys, urllib, datetime,
  pathlib, sqlite3`. Variance-ratio, autocorr, Sharpe, CPCV, PSR, DSR are all hand-implemented
  (`validation.py`, `run_mean_reversion.py`).
- **OHLCV load helper** (`run_tf_grid.py:96`):
  ```python
  def load_cached(tok: str, tf: str) -> dict | None:
      # tf=="1m" -> CACHE_1M/{tok}USDT_1m_90d.json
      # else     -> CACHE_5M_4H_1H/{tok}USDT_{tf}_365d.json
      # returns {opens,highs,lows,closes,times}, sliced to [START_MS, END_MS]
  ```
  The Phase-C scripts override `load_cached` + `START_MS/END_MS` to point at `ohlcv_cache_720d`
  (720d window) — see top of `run_mean_reversion.py` / `run_volume_breakdown.py`. **No resampling
  helper** — each timeframe is fetched/stored separately (Binance klines per interval); analysis
  reads the pre-stored TF directly.
- **In-sample/OOS split in code:** descriptive = chronological 70/30
  (`sorted(..., key=lambda s: s["ts"]); cut=int(len(sg)*0.7)`); formal = Held-Out Lockbox
  (`HELD_OUT_DAYS=90` reserved, `walk_forward.py` + `scripts/validate_baseline_held_out.py`,
  `docs/held_out_protocol.md`).
- **Experiment outputs/reports convention:** human-readable `*.md` in the **repo root** (Phase-C
  reports), design/protocol docs under `docs/`, dated agent-audit reports under `.claude/reports/`,
  machine results in `data/*.json` (e.g. `tpgeo_results.json`) and `data/breakout.db`. The analysis
  scripts run **in-memory and write NO DB rows**.
