## HIGH findings (3)

### H1 — Pre-sweep FVG false confluence at W>2
**File:** `crt_engine.py:283` (probe loop in `_check_confluence`)
**Source:** Backtest bias detector
**Detail:** When `H4_CRT_FVG_PROBE_WIDTH > 2`, the probe loop iterates from `mss_bar - (W-1)` to `mss_bar`. The bar at `d = mss-4` (W=5) can pre-date `sweep_5m_idx` entirely. An FVG matched at that position formed BEFORE the C2 sweep — it is not the "institutional defense zone" the canonical CRT theory describes.
**Empirical evidence:** Run #1837 (W=4 alone) added 4 signals but dropped DSR 87.6 → 83.4% (-4.2pp). The +4 signals were predominantly pre-sweep false-confluence matches.
**Live/BT parity:** Exact — both paths use the same code, so the bias is symmetric (no lookahead). It is a SIGNAL QUALITY issue.
**Fix:** Add `if d < sweep_5m_idx: continue` inside the probe loop at `crt_engine.py:283`. One line.

### H2 — `consecutive_fail_max=500` effectively disables basin-lost guard
**File:** `scripts/autonomous_explorer.py:232`
**Source:** Explorer code review
**Detail:** Raised from 100 to 500 to tolerate config_hash collision investigation. At ~11 min/trial, 500 consecutive fails = ~92 hours of continuous failure before tripping. CLAUDE.md invariant #12 calls for ~50; 500 is 10× over spec.
**Impact:** Operator could leave a broken explorer session running overnight + all the next day without auto-pause.
**Fix:** Lower to 150-200, OR AND-combine with `best_dsr_pct < pin_dsr - 2pp` to trip earlier when the basin is actually lost.

### H3 — `c2_time` docstring says "close time" but stores OPEN time
**Files:** `crt_engine.py:452` (docstring) + `crt_engine.py:558` (assignment `c2_time = h4_times[c2_idx]`)
**Source:** Backtest bias detector
**Detail:** Binance kline `times[i]` is the OPEN time of the bar (line 0 of the kline array). The docstring claims `"c2_time": <time>, # close time of C2 (for downstream timing)` but the stored value is the open time. Functionally consistent today (both live and BT use the same value), but a future developer "fixing" this by adding +4h would silently break working behavior.
**Fix:** Update docstring to: `"c2_time": Binance H4 OPEN time of C2 (NOT close — close is open+4h)`.

## MEDIUM findings (8)

### M1 — TTL knob structurally inert at current `CRT_FORWARD_BARS=864`
**Source:** Honest metrics + Bias detector (convergent observation)
**Detail:** `CRT_FORWARD_BARS=864` = 72 hours outcome window. `H4_CRT_MITIGATION_TTL_H ≤ 72` means a consumed zone cannot become re-eligible WITHIN the forward window of the same signal that consumed it. At current CRT signal frequency (~15-17/month per token), same-zone re-fires are extremely rare even at TTL=24h.
**Empirical evidence:** Run #1836 (W=4 + TTL=72) produced bit-identical metrics to Run #1837 (W=4 + TTL=0) — TTL had zero behavioral effect.
**Impact:** Wastes Optuna trial budget; inflates DSR n_trials (makes gate harder) without providing independent quality signal.
**Recommendation:** Either remove TTL from explorer space until FORWARD_BARS shortens, OR widen TTL range to {0, 168, 336, 720} where re-eligibility CAN fire.

### M2 — Code-drift guard message omits `crt_engine.py`
**File:** `scripts/autonomous_explorer.py:767`
**Detail:** Message hardcodes `"config.py / backtest.py / ict_engine.py"` but `CODE_FILES` (line 86) now also includes `crt_engine.py`. A CRT-only drift trip produces a misleading triage message.
**Fix:** Build message string from `CODE_FILES` dynamically.

### M3 — TTL prune cadence asymmetry (live 5min vs BT 4h)
**Files:** `crypto_alert.py:933` (per scan cycle) vs `backtest.py:1441` (per H4 iteration)
**Detail:** At TTL=24h, a zone with `c1_time = now - 23h55m` would be un-pruned in backtest but pruned in live during the next 5-min cycle. Maximum drift ~4h per TTL period.
**Direction of bias:** Backtest conservatively under-counts re-fire signals (acceptable direction).
**Fix optional:** Document the cadence delta in `prune_consumed_zones` docstring.

### M4 — `_reproduce()` swallows `--clear-checkpoint` non-zero rc silently
**File:** `scripts/autonomous_explorer.py:964-967`
**Detail:** Unlike `_precache_warm` (which checks subprocess rc), the reproducibility-pass clear-checkpoint call ignores failure. A stale checkpoint could leak into the repro backtest causing false `skip:reproducibility`.
**Fix:** Mirror the precache warning path.

### M5 — `start_sr_std=0` silently disables guard #5
**File:** `scripts/autonomous_explorer.py:770`
**Detail:** sr_trial_std jump check gated on `self.start_sr_std > 0`. On a fresh DB or after pool reset, returns 0.0, and guard #5 is permanently dormant for the session with NO log.
**Fix:** Add a one-line warning at session start when `start_sr_std == 0`.

### M6 — Cycle-12 search space ~16× larger, trial budget unchanged
**File:** `scripts/autonomous_explorer.py:551-562`
**Detail:** New params (FVG_PROBE_WIDTH: 4 values, MITIGATION_TTL_H: 4 values) raise categorical space ~16×. Default `EXPLORER_TRIALS=50` will under-sample for TPE convergence.
**Fix:** Bump `deploy/env.explorer.example` default to 80; document in CLAUDE.md §3.

### M7 — Cross-config sr_trial_std uses pre-CRT 5M_SWEEP pool
**File:** `backtest.py:4168-4175` (read of `bot_state.cross_config_sr_trial_std`)
**Detail:** Current canonical `sr_trial_std=0.0836` derives from 24 5M_SWEEP-era configs. CRT signals have structurally different Sharpe distributions (higher frequency, lower mean, different skew). The CRT DSR gate may be biased optimistic OR conservative depending on whether CRT std is lower OR higher than 0.0836.
**Recommendation (operational, not code):** Run `compute_cross_config_sr_std.py --scanner-mode crt_only` after each CRT explorer session. Track the emerging CRT-specific std until ≥10 distinct CRT configs accumulate, then promote that std as the CRT-mode canonical.

### M8 — Legacy pin q05 derivation path is unlogged
**File:** `scripts/autonomous_explorer.py:937-938, 950-951`
**Detail:** Eligibility check derives q05 from `pin_mean - 1.645 * pin_std` when pin's `q05` field is missing (pre-q05-era pins). Normal approximation can over-state q05 if fold WRs are left-skewed. The derivation path fires silently.
**Fix:** Log when the derivation path is taken so operator knows pin is pre-q05 era.
