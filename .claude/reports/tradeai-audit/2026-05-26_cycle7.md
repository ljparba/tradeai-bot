## 3. NEW Cycle-7 Findings

### CRITICAL — 0

### SERIOUS — 1

- [ ] **S-CY7-1** (Honest Metrics + Adaptive): R1's `_dsr_gate_lr_scale()` treats MARGINAL as inert (full LR), but `validation.py` produces MARGINAL in TWO structurally different cases:
  - **Case a** (safe): WR borderline 55-58% AND DSR passed — selection bias survived, edge is weak but real. Full-rate learning defensible.
  - **Case b** (unsafe): WR ≥ 55% AND `dsr=None` (no multiple-testing correction applied at all). The C-B fix correctly caps verdict at MARGINAL when DSR is None, but R1's gate then treats this MARGINAL identically to the safe Case (a) → full-rate OGD learning on a verdict that wasn't honestly stress-tested.
  - `dsr_gate_applied` exists in the verdict blob (C-B fix output) but is NOT in the JSON persisted at `backtest.py:3296-3304`. The adaptive engine therefore cannot distinguish the two MARGINAL cases.
  - **Fix:** add `"dsr_gate_applied": _cpcv.get("dsr_gate_applied")` to verdict blob; in adaptive_engine `_dsr_gate_lr_scale()`, apply soft scaling (0.5×) when `verdict == "MARGINAL" and not dsr_gate_applied`.

### HIGH — 3 deployment / wiring items

- [ ] **R5 deployment** (Data Pipeline + Resilience): `tradeai-monitor.timer` units exist in `deploy/` and ship in cycle-6 commit, but `systemctl list-timers` confirms the operator has already installed them (per earlier conversation screenshot showing `Wed 2026-05-27 04:34:26 CEST` next fire). **CLOSED operationally — verified via journal output.**

- [ ] **NEW H-CY7-1** (Backtest Validity, cross-domain): `autonomous_explorer.py` launches `backtest.py` as a subprocess but does NOT set `BOOTSTRAP_AFTER_RUN=0` in the subprocess environment. R3 protection is opt-in; the explorer should opt out so every trial avoids overwriting `backtest_token_weights`. One-line env override in the subprocess launch.

- [ ] **NEW H-CY7-2** (Data Pipeline): `scripts/run_monitoring_with_alert.sh:66` — `<pre>$SUMMARY</pre>` embeds the unescaped monitoring report text inside `parse_mode=HTML`. If the report ever contains `<`, `>`, or `&` (currently safe but free-form alert text could include them), Telegram returns HTTP 400 and the CRIT alert is silently dropped (`curl > /dev/null 2>&1`). The one time the alert matters most. Fix: `sed 's/&/\&amp;/g; s/</\&lt;/g; s/>/\&gt;/g'` before embedding, or remove `parse_mode=HTML` for the SUMMARY message and use Markdown for the body.

### MEDIUM — 4

- [ ] **NEW M-CY7-1** (Risk + Config, cross-domain): three new env-driven OGD knobs (`OGD_DSR_GATE`, `OGD_FREEZE_MODE`, `OGD_WARMUP_FLOOR`) are NOT in `backtest.py:_compute_run_config_hash()`. At default values this is inert; if operator ever varies them across explorer trials, the M-H ESCALATED collision-vector pattern recurs. Fix: add to hash payload (same pattern as REALISTIC_EXECUTION + HELD_OUT_DAYS).

- [ ] **NEW M-CY7-2** (Backtest Validity): `print_report(all_signals)` + `run_rolling_walk_forward(all_signals)` at `backtest.py:3182-3183` use the FULL pool even when `HELD_OUT_DAYS>0`. Cosmetic only — these are display functions, not verdict computations — but creates an inconsistency where the printed WFV header includes held-out signals while CPCV correctly uses tuning-only. Fix: pass `_tune_sigs` after the split is computed.

- [ ] **NEW M-CY7-3** (Adaptive): R9's active-mode FREEZE branch (`adaptive_engine.py:772-776`) still increments `_n_effective` even though the gradient was discarded. Effective-sample diagnostic overstates real learning during freeze periods. Easy fix: move `_n_effective` increment below the freeze return into the success path only. Inert while default mode=shadow.

- [ ] **NEW M-CY7-4** (Adaptive): `_check_dsr_fail_streak()` uses `latest_cpcv_verdict.updated_at` as the FAIL-streak onset timestamp, but each new backtest re-writes `updated_at`. A FAIL→FAIL re-run resets the 24h timer. Add separate `first_fail_onset` field in the blob for tighter semantics.

### LOW — 5

- [ ] R5 wrapper missing `--max-time` on curl — Telegram hang blocks up to 300s before SIGKILL
- [ ] `_maybe_alert_freeze` `conn.close()` not in `try/finally` — connection leaks on DB exception (rare)
- [ ] R7 regime column lacks index for future `(token, regime)` queries
- [ ] R10 panel labels bootstrap-fallback weights identically to live-touched weights — operator could mistake stale bootstrap pins for live degeneration
- [ ] Adaptive env knobs (`OGD_*`) not surfaced via `config.py:__all__` SSoT-exception declaration

## 5. Executive Summary

The TradeAI v13 system at **9.30/10** is the strongest scorecard in project history, narrowly surpassing cycle-6's 9.23 peak hours earlier and well above the cycle-12 termination ceiling (9.025). The R1-R10 master-audit sweep landed cleanly across all 11 independent agent perspectives — six dimensions improved, five held, zero regressed. Honest Metrics held its 9.5 only because cycle-7 surfaced one new SERIOUS finding (S-CY7-1, R1 gate doesn't distinguish DSR-absent MARGINAL from DSR-passed MARGINAL) that offsets the R1 gate's structural benefit; the math itself is correct and the operational impact is currently inert because the active baseline (Run-81) passes DSR cleanly. Adaptive Learning at 9.7 and OGD Weight Quality at 9.6 are the dimensions that benefited most from today's sweep — the DSR-aware learning gate, soft warmup ramp, event-driven decay, forensic columns, regime labeling, learning-freeze predicate, and per-token dashboard panel together transformed the adaptive layer from "documented but blind" to "instrumented, gated, and shock-resistant." The cumulative effect: the adaptive subsystem can now fail gracefully when statistical validation breaks (R1 + R9), explain itself when the operator investigates (R4 + R7 + R10), and resist contamination from explorer trials (R3) — all without compromising the H6 isolation that protects CPCV validity.

The Template dimension remains the binding floor at 6.5/10, but this is structural (n=35 produces insufficient tier discrimination, and live signal history was wiped during the Phase-B revert). Template tier calibration cannot improve without either ~30 closed live paper signals or a fundamental redefinition of Tier A (deferred until paper data accrues).

Paper trading is **unconditional GO**. The adaptive layer is in the best operational state of the project's history.
