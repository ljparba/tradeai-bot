## 3. NEW Cycle-14 HIGH Findings (BOTH FIXED IN SAME SESSION)

### H-CY14-1 (Adaptive) — 6× n_updates inflation in M-CY13-1 hydration
**Source:** adaptive-learning-code-reviewer agent
**Root cause:** My cycle-13 M-CY13-1 hydration used `COUNT(*) FROM weight_history` to count signal close events, but `weight_history` writes ONE ROW PER FEATURE PER CLOSE (6 features × 2 snapshots = 12 rows/close). Hydration inflated `_n[TON]` from 2 actual closes to 12. Next `_persist_token` would write `token_weights.n_updates = 13` (corrupting the very observability metric the fix was meant to repair).

**Fix shipped this session:** [adaptive_engine.py:412](adaptive_engine.py#L412) — query now `COUNT(DISTINCT recorded_at)` instead of `COUNT(*)`. Empirically verified: TON wrong-count = 12, right-count = 1. The fix gives the correct authoritative close count.

### H-CY14-T1 (Template) — Tier A BUY destroys capital
**Source:** template-tier-calibrator agent
**Root cause:** H-CY13-T2 hypothesis was partially wrong. Relaxing the MSS gate for BUY only moved Tier A BUY WR from 20% → 31.4%, still well below break-even (-0.207 R/trade cumulative across 35 paper trades). The FVG confluence itself anti-selects on the BUY/SSL_CRT side — likely picking up gap-down FVGs in retracements that re-attract sellers.

**Fix shipped this session:** [strategy_templates.py:481](strategy_templates.py#L481) — Tier A is now **SELL-only**. BUY signals fall to Tier B (canonical 68.2% WR / +0.635 R per cumulative data) or Tier C (paper-only catchall). Tier A preserves 75% WR / +0.723 R premium tier identity. Re-backtest confirms: Run #2008 Tier A = SELL only n=8 WR=75% (clean canonical premium).
