## Critical Regressions This Cycle

### REGRESSION-A: Template DR Confluence Logic — 0/42 signals match `strategy_templates.py:135-137`

**Severity:** CRITICAL
**Files:** `strategy_templates.py:135-137,205-207,273-275`
**Finding:** Template scoring code states `BUY+DISCOUNT = aligned`. Run #85 data shows the bot's actual signal geometry places every BUY in PREMIUM/UNKNOWN and every SELL in DISCOUNT/UNKNOWN — making the DR confluence factor satisfiable in **0/42 signals**. Tier-A's "5-of-5 confluences" is functionally "4-of-4 + 1-impossible." This silently subtracts 1 from every Tier-A `required_hit`, collapsing the tiering system to a single tier.

### REGRESSION-B: SMT Bonus Wrong-Signed vs Empirical Data

**Severity:** CRITICAL
**Files:** `strategy_templates.py:143-144,213-214,269-270`
**Finding:** Code applies `bonus -= 0.10` for SMT-confirmed (comment cites "anti-predictive per Run 48"). Run #85 actuals show **SMT=True → 78.8% WR (n=33), SMT=False → 66.7% WR (n=9)** — a +12.1pp edge. The penalty is corroded by ~5 cycles of accumulated learning. Should be `+0.10` or removed.

### REGRESSION-C: DSR Silently Non-Functional (`DB_PATH` NameError)

**Severity:** CRITICAL
**File:** `backtest.py:2839`
**Finding:** CPCV/DSR block references undefined `DB_PATH`; the module defines `BT_DB_PATH` at line 151. Outer `except` swallows the NameError. Effect: deflated Sharpe never computed, so the reported Sharpe is never corrected for selection bias across 93+ historical optimizer runs. This is the only anti-multiple-comparison safeguard in the backtest, and it is silently broken. One-character fix: `DB_PATH` → `BT_DB_PATH`.

### REGRESSION-D: H21 PARTIAL Counting Regression in Tracker Dashboard

**Severity:** CRITICAL
**Files:** `tracker.py:184,197,199,272`
**Finding:** Per-token `w` (line 184) and `wr` (line 199) treat `PARTIAL/PARTIAL_TP1/PARTIAL_TP2` as full wins (1.0). `recent_wr` (lines 197, 272) only matches `r=="PARTIAL"` so `PARTIAL_TP1/2` count as 0 wins. Two inconsistent counting bugs in the dashboard intelligence path. Same class as TT-7 (which fixed `_tune_wr()`).
