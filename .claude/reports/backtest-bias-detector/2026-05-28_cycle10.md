### NEW-2 (LOW — Performance: `precompute_tf(c1h)` Inside H4 Loop)

**Severity:** LOW — performance only, no bias
**Location:** `backtest.py:1468`

**Finding:** `precompute_tf(c1h)` is called inside `for h4_end in range(h4_window, n4):` at `backtest.py:1468`, but only when a CRT setup was detected and earlier gates (session, bias) passed. For a 365-day backtest with ~2190 H4 bars, the actual call count is proportional to the session+bias gate pass-rate (empirically ~5-15% of bars). Each call recomputes EMA50/200 over the full 1H dataset (~8760 bars). At ~200 calls per token × 10 tokens = ~2000 calls, this adds ~10-20 seconds to a full backtest run.

**No bias:** EMA computation is causal (recursive forward from bar 0). Each EMA value at index t uses only bars 0..t. The `_lookup_trend` bisect correctly anchors to the historical bar. The full-dataset computation does not leak future values into past indices.

**Fix:** Hoist `_ind1h = precompute_tf(c1h)` out of the loop to before `for h4_end in range(...)`. The 5M_SWEEP path already does this at `backtest.py:725`. One-line change.

**Classification:** NEW FINDING. LOW severity (performance only, not bias).
